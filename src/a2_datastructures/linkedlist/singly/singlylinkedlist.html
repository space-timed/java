The Singly Linked List

A fundamental linear data structure made of linked nodes.

Concept Definition

A Singly Linked List is a common data structure made of a chain of nodes. Each node contains a value and a pointer (reference) to the next node in the chain.

  • Head: Points to the first node.
  • Tail: The last node points to null.
  • Empty List: Head pointer points to null.
  • Traversal: Elements are accessed linearly from head to tail.

Java Implementation

Java// Node class for a singly linked list
class Node {
  int value;
  Node next;

  public Node(int value) {
    this.value = value;
    this.next = null;
  }
}
Javaclass SinglyLinkedList {
  Node head;

  public SinglyLinkedList() {
    this.head = null;
  }

  // Method to add a node to the list
  public void add(int value) {
    Node newNode = new Node(value);

    if (this.head == null) {
      this.head = newNode;
    } else {
      Node current = this.head;
      while (current.next != null) {
        current = current.next;
      }
      current.next = newNode;
    }
  }

  // Method to remove a node from the list
  public void remove(int value) {
    if (this.head == null) return;

    if (this.head.value == value) {
      this.head = this.head.next;
      return;
    }

    Node current = this.head;
    while (current.next != null) {
      if (current.next.value == value) {
        current.next = current.next.next;
        return;
      }
      current = current.next;
    }
  }

  // Method to search for a value
  public boolean search(int value) {
    Node current = this.head;
    while (current != null) {
      if (current.value == value) return true;
      current = current.next;
    }
    return false;
  }
}
Javapublic class Main {
  public static void main(String[] args) {
    SinglyLinkedList list = new SinglyLinkedList();

    list.add(5);
    list.add(10);
    list.add(15);

    list.remove(10);

    if (list.search(15)) {
      System.out.println("15 was found in the list");
    }

    // Access by index example
    int value = list.get(1); // Returns value of 2nd node

    // Traverse and Print
    Node current = list.head;
    while (current != null) {
      System.out.println(current.value);
      current = current.next;
    }
  }
}

Key Features

  • Ordered collection; supports duplicates.
  • Allows null elements.
  • Supports index-based operations (traverses from start/end whichever is closer).
  • Fail-fast Iterators: Throws ConcurrentModificationException if modified after iterator creation.
  • Maintains insertion order.

Thread Safety Note

LinkedList is not synchronized. To make it thread-safe, use:

List list = Collections.synchronizedList(new LinkedList(...));

Trade-offs

Benefits

  • Efficient insertion and deletion.
  • Dynamic size (grows/shrinks as needed).
  • Uses less memory than some other structures (like doubly linked lists).
  • Great for implementing Stacks and Queues.

Drawbacks

  • No random access (must iterate to index).
  • Search is slow (O(n)).
  • Difficult to sort efficiently.
  • Cannot traverse backwards (only has reference to 'next').

Real-World Applications

OS Memory Management

Managing blocks of memory allocation and tracking free space.

Undo/Redo Functionality

Storing history in text editors or graphic design software.

Transportation Systems

Representing stop schedules (e.g., train stops along a route).

Search Results

Handling dynamic lists of items like search engine hits.

Deep Dive & Resources

Common Mistakes & Pitfalls +
  • Losing the Head: Forgetting to update the head pointer when deleting the first node.
  • Null Pointer Exceptions: Accessing current.next without checking if current is null.
  • Memory Leaks: In some languages, not properly unlinking nodes can prevent garbage collection.
  • Infinite Loops: Creating a cycle by pointing a node back to a previous node in the list.
Key Takeaways +

1. Singly Linked Lists are ideal when frequent insertions/deletions are needed but random access is not.

2. They are the building blocks for Stacks and Queues.

3. Every node is an object, and they are linked via references, meaning they don't need to be contiguous in memory.
