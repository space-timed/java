Definition

An array is a collection of items stored at contiguous memory locations. The idea is to store multiple items of the same type together. This makes it easier to calculate the position of each element by simply adding an offset to a base value, i.e., the memory location of the first element of the array (generally denoted by the name of the array).

Important Constraint: An array's size is set at the time it is created, and it cannot be changed.

Detailed Explanation (Java Context)

In Java, arrays have specific characteristics and rules:

  • All arrays are dynamically allocated.
  • Arrays are stored in contagious memory [consecutive memory locations].
  • Since arrays are objects in Java, we can find their length using the object property length. This is different from C/C++, where we find length using sizeof.
  • A Java array variable can also be declared like other variables with [] after the data type.
  • The variables in the array are ordered, and each has an index beginning from 0.
  • Java array can also be used as a static field, a local variable, or a method parameter.
  • The size of an array must be specified by int or short value and not long.
  • The direct superclass of an array type is Object.
  • Every array type implements the interfaces Cloneable and java.io.Serializable.
  • This storage of arrays helps us randomly accessing the elements of an array [Support Random Access].
  • The size of the array cannot be altered(once initialized). However, an array reference can be made to point to another array.
  • An array's size is set at the time it is created, and it cannot be changed.

Creation & Initialization

Here is an example of how to create, initialize, and declare an array in Java:

// create an array of strings with a size of 5
String[] names = new String[5];

// initialize the first element in the array
names[0] = "Alice";

// initialize the second element in the array
names[1] = "Bob";

// and so on...
names[2] = "Carol";
names[3] = "David";
names[4] = "Emily";

// declare an array of integers and initialize it with the values 1, 2, 3, 4, and 5
int[] numbers = {1, 2, 3, 4, 5};

int intArray[];          // declaring array
intArray = new int[20];  // allocating memory to array

int[] intArray = new int[20]; // combining both statements in one

In the first example, we create an array of strings with a size of 5. This means that the array can hold up to 5 strings. We then initialize the first element in the array by assigning a value to the element at index 0. We do the same for the second element at index 1, and so on.

In the second example, we declare an array of integers and initialize it with the values 1, 2, 3, 4, and 5. This is a shortcut that allows us to create and initialize the array in a single step.

Once an array is created, we can access its elements by using the array's name followed by the element's index in square brackets. For example, we could retrieve the second element in the names array like this:

String secondName = names[1];

We can also use a loop to iterate over the elements in an array and perform some action on each element. Here is an example of how to print all the elements in the names array:

for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}

Important Methods to Work with Arrays

Java provides several built-in methods for working with arrays. Some of the most common array methods are:

  • Arrays.sort(): This method sorts the elements in an array in ascending order. It can be used to sort arrays of primitive types, such as int, double, and char, as well as arrays of objects, such as strings and custom objects.
  • Arrays.binarySearch(): This method performs a binary search on a sorted array and returns the index of the specified element. If the element is not found, it returns a negative value.
  • Arrays.copyOf(): This method creates a new array with the specified size and copies the elements from the original array to the new array.
  • Arrays.copyOfRange(): This method creates a new array with the specified size and copies a range of elements from the original array to the new array.
  • Arrays.fill(): This method fills an array with the specified value.
  • Arrays.equals(): This method compares two arrays and returns true if they are equal, and false if they are not equal.
  • Arrays.toString(): This method returns a string representation of the contents of an array.
  • Arrays.asList(): This method creates a list from an array.

Here is an example of how to use some of these methods:

int[] numbers = {5, 3, 7, 1, 2};

// sort the array in ascending order
Arrays.sort(numbers);

// search for the number 5 in the array
int index = Arrays.binarySearch(numbers, 5);

// create a new array with a size of 10
int[] bigger = Arrays.copyOf(numbers, 10);

// fill the remaining elements in the new array with 0
Arrays.fill(bigger, numbers.length, bigger.length, 0);

// compare the original array with the new array
boolean equal = Arrays.equals(numbers, bigger);

// create a list from the new array
List<Integer> list = Arrays.asList(bigger);

  • Size: The size of an array cannot be altered at runtime since data can only be stored in contiguous blocks of memory in an array. However, due to the node structure of a linked list, its size can be altered easily since each node points to the next one such that data can exist at scattered (non-contiguous) addresses.
  • Memory allocation: For arrays, memory is allocated at compile time whereas for linked lists memory is allocated at runtime. But, a dynamically allocated array also allocates memory at runtime.
  • Memory efficiency: For the same number of elements, the linked list uses more memory due to its node structure since each node stores a reference to the next node along with the data. However, linked lists may use less memory overall compared to arrays when there is uncertainty about size or there are large variations in the size of data elements.
  • Execution time: In the case of a linked list, all the previous elements must be traversed to reach any element whereas elements in an array can be accessed directly using their index. As a result, some operations such as modifying an element are faster in arrays, while some other operations such as inserting an element are faster in linked lists.

Benefits of using arrays

  • Arrays allow for the efficient storage and retrieval of data by using a numeric index.
  • Arrays provide a way to organize and manipulate large amounts of data in a structured manner.
  • Arrays allow for the easy iteration and traversal of data using looping constructs such as for and foreach loops.
  • Arrays allow for the easy implementation of common data structures such as stacks, queues, and lists.
  • Arrays provide a way to perform bulk operations on data, such as sorting, filtering, and transforming, using methods from the Java Collections framework.
  • Arrays allow for the efficient use of memory by allocating a contiguous block of memory to store data, reducing the overhead of individual object creation and garbage collection.
  • Arrays provide a way to implement algorithms that require the efficient manipulation of large amounts of data, such as search and sorting algorithms.

Disadvantages of arrays

  • You need to specify how many elements you're going to store in your array ahead of time and We can not increase or decrease the size of the Array after creation.
  • You have to shift the other elements to fill in or close gaps, which takes worst-case O(n) time.
  • Can store a single type of primitives only.

Real-world applications

  • Storing and organizing large amounts of data, such as a list of customer names, product prices, or inventory levels.
  • Implementing data structures such as stacks, queues, and lists to store and manipulate data in a structured manner.
  • Performing bulk operations on data, such as sorting, filtering, and transforming, using methods from the Java Collections framework.
  • Implementing algorithms that require the efficient manipulation of large amounts of data, such as search and sorting algorithms.
  • Storing and processing multi-dimensional data, such as a matrix or grid of values, for applications such as image processing and scientific simulations.

Interview Questions & Prep

Conceptual Questions (Click to Reveal)

Why is the complexity of fetching from an Array O(1)?

In an Array, objects are stored in continuous memory location. So, if you know the address of the base object then you will be able to find the address of the ith object.

address(a[i]) = address(a[0]) + i*size(object)

This term is independent of n, so the time complexity of fetching from an Array is O(1).

What is the default value of Array in Java?

If we don't specify the values by ourselves, then Java assigns default values in them which are 0 for byte, short, int, and long, 0.0 for float and double, false for boolean, and null for objects respectively.

Where is an Array stored in JVM memory?

An Array is an object in java. So, Array is stored in heap memory in Java Virtual Machine.

When will we get ArrayIndexOutOfBounds Exception?

ArrayIndexOutOfBounds is a runtime exception that occurs when the program tries to access the invalid index of an array such as an Index higher than the size of the array or a negative index.

How do you remove a particular element from an array?

You can't directly remove elements from the original array, as arrays are fixed sets and the size can't change therefore the interviewer is looking for you to suggest an alternate solution and address the issue that the question presents. The best way to remove an element would be to create a new array. In this array, you could include copies of elements of the first array and omit only the element you want to remove.

Another approach is searching for the target element in the array and then moving all the elements in one position back which are on the right side of the target element.

Featured: How do you merge two sorted arrays into one sorted array?

During a programming interview, the employer may ask you to demonstrate your ability to work with more complex coding functions, such as merging arrays.

Approach 1:
To merge two arrays, you can create a new array of size equal to the sum of two arrays. After that, you can copy the elements from the first array into the new one. Then you can traverse the second array and insert elements from it into the new one using insertion sort. This method takes:
Time complexity: O(n1 * n2)
Extra Space: O(n1+n2)

Approach 2 using Heap:
1. Convert the second array to min-heap.
2. Now, the last M elements of the sorted merged array are in the min_heap or second array.
3. Apply in-place heapsort to the second array to sort them.
